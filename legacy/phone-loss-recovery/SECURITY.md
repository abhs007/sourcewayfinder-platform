# Security and privacy

Navigator and study state remain in memory, outside URLs, automatic storage and uploads. Exports are explicitly requested downloads; users manage downloaded copies separately. Navigation/reload discards the session. Hosting providers can process ordinary connection metadata. Official links open on selection. This module does not use Pause & Verify's separate report API.

Report software vulnerabilities privately to abhishek.vaishnav@yahoo.com without secrets. This address is not an incident-response promise. Use public issues for non-sensitive source corrections. No carrier-system testing is authorized by this project. No offline service worker is installed; integrated hosts must exclude /phone-loss/. Source dates do not establish live backend enforcement.
