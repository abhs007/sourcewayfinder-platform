# Contributing

Propose a public source, passage locator, provider, account/plan scope, operation and interpretation in an issue or pull request. Never submit account identifiers, credentials, employer-confidential data or raw customer records. Guidance needs source IDs, official URLs, review dates, explicit prerequisites and limitations. Preserve disagreements and historical files. A successful fetch is not a content review.

Run validation, unit and browser tests; add meaningful regression fixtures for behavioral changes. Document substantive review and corrections. Do not claim independent validation unless a distinct qualified person performed and documented it. Original code contributions use MIT and original content CC BY 4.0; contributors must have the right to license them.
